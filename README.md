# weasel
A simple evolutionary algorithm and its analysis. The initial idea for this specific algorithm was due to Dawkins in the book The Blind Watchmaker. However, it fits into an older line of work on optimization algorithms stretching back to the 1960s. This type of analysis is in the literature (going far beyond what I did here and for more complicated problems), but maybe putting it here will make it more accessible for students. Essentially, this is just my attempt to understand it and work it out for myself the physicist's way.
